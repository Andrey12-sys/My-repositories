## Мой сайт

Сайт представляет собой удобную стартовую страницу со ссылками на учебные материалы.

- **[Перейти на сайт](https://andrey12-sys.github.io/My-repositories/)** — адрес GitHub Pages после активации публикации.
- **[Репозиторий сайта](https://github.com/Andrey12-sys/My-repositories)** — все исходные файлы проекта.
- **[Исходный код главной страницы](./index.html)** — HTML и CSS сайта.

### Как включить GitHub Pages

1. Открыть [Settings → Pages](https://github.com/Andrey12-sys/My-repositories/settings/pages).
2. В разделе *Build and deployment* выбрать **Deploy from a branch**.
3. Выбрать ветку **DFGDFG** и папку **/(root)**.
4. Нажать **Save**, затем дождаться публикации.

После успешной публикации сайт должен открываться по ссылке выше.
